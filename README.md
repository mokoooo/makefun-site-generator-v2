A dependency-free, from-scratch reimplementation of the makefun-site 1.0.0 static site generator (front matter, Markdown subset, template dialect, slug rules, collections, tag pages and build report), written to return byte-identical output trees while running fast. `solve.js` exports `run(input)`; `main.ts` is the standard harness driver that reads `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts  # reads /input/cases.json, writes /output/answers.json
```
